# Deprecated alias for `add_factor_experience()`

`add_portfolio_experience()` is deprecated. Use
[`add_factor_experience()`](https://mharinga.github.io/insurancerating/reference/add_factor_experience.md)
instead. Both the `data` and `observed` input methods remain supported.

## Usage

``` r
add_portfolio_experience(x, ...)
```

## Arguments

- x:

  A `rating_table` object returned by
  [`rating_table()`](https://mharinga.github.io/insurancerating/reference/rating_table.md).

- ...:

  Arguments forwarded to
  [`add_factor_experience()`](https://mharinga.github.io/insurancerating/reference/add_factor_experience.md).

## Value

See
[`add_factor_experience()`](https://mharinga.github.io/insurancerating/reference/add_factor_experience.md).
