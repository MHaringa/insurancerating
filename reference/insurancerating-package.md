# Actuarial building blocks for insurance pricing

Analyse portfolio experience, interpret fitted pricing models, make
explicit tariff adjustments and validate models and tariffs. The tools
complement standard R modelling functions such as
[`stats::glm()`](https://rdrr.io/r/stats/glm.html). Use them separately
or combine them to suit the portfolio and question.
