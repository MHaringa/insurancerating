# Plot individual tariff impact bands

Plot individual tariff impact bands

## Usage

``` r
# S3 method for class 'refinement_audit'
autoplot(object, ...)
```

## Arguments

- object:

  An
  [`audit_refinement()`](https://mharinga.github.io/insurancerating/reference/audit_refinement.md)
  result with `individual = TRUE`.

- ...:

  Not used.

## Value

A ggplot object.
